# NEXUS: Sites design reference

The founder identified the private **SIT Mysuru · College OS** prototype in ChatGPT Sites as the design and writing reference. The v2 saved overview was inspected. It is distinct from the public guide demo. Do not change the private prototype or copy its example students, calculated metrics, speculative features or role-switcher implementation into the authenticated product.

| Reference design | Authenticated NEXUS |
| --- | --- |
| Soft cool-gray canvas, near-white workspace and restrained blue active state | Shared light/dark semantic colors and neutral desktop rail, plus mobile bottom navigation |
| Sans-serif headline, small uppercase context, quiet breadcrumb | Bold locally available UI sans, a factual workspace kicker, role and institution identified, breadcrumb on wide screens |
| Blue-tinted priority card, calm AURA module and generous spacing | Real class and due-work cards with independent priorities, subtle tint, shorter AURA copy that says which records it reads |
| Clear verbs and friendly, professional language | Use “Today’s timetable,” “Create assignment,” and other exact actions. State who can see changes and what remains unconfirmed in context |
| Illustrative role switcher, assistant suggestions and metrics in the prototype | No mock search, arbitrary role switching, artificial counts, or unsupported agent actions copied into the real app |

Keep the information hierarchy proven in the usability pass even when the concept presentation differs. Verify keyboard focus, active nav, dark and light appearance, reduced motion, compact layouts, and actual workflows with fictional records before a pilot. Native browser animation does not establish device performance or adoption. The scope of this pass is the shared shell and the Student, Faculty and Timetable entry points, not completion of all five prototype experiences.
