# NEXUS campus workspace

Use the semantic tokens in `app/tokens.css`. Body text, controls and comparison metrics use the UI sans stack and tabular numbers. Headings use a bold UI sans rather than a separate serif. Font stacks include Kannada fallbacks and use locally available fonts. Near-white, cool gray and blue establish the hierarchy, with restrained accents for different states. Every status has a text label.

The shared shell exposes institution, workspace, account controls and appearance. Appearance supports System, Light and Dark, with a validated cookie read on the server. It has no effect on authorization. Keep independently important records, such as the next class and next coursework deadline, visible side by side or stacked on a phone. Show the source and link directly to the record. Keep longer lists and secondary work below the first decision. Reuse the timeline, metric links, native forms and dialog components for these patterns.

At narrow widths the menu shows up to four primary routes and a More button for remaining authorized destinations. Dialogs retain native modal semantics and visible close controls. The timetable includes a chronological text list alongside its visual grid. Empty states distinguish missing records from a measured zero.
