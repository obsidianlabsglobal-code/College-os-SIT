# Decisions

- Use a modular monolith and relational PostgreSQL. The first workflows use joined records and transactions. Revisit topology when measured performance or isolation requirements justify it.
- Use Better Auth and persisted sessions. Resolve institutional grants inside application services and maintain a separate migration identity.
- Keep small release-candidate attachments in PostgreSQL behind a storage boundary. File and audit writes roll back together. Bound payload size to 4 MiB for the Vercel Functions request limit and prepare private object storage and scanning before institutional rollout.
- Reject late submissions and permit one final submission in Release 1. Verify extension and resubmission requirements with the pilot before adding policy.
- Preserve published grade versions while corrections are drafted and retain superseded draft revisions. Lock grade writes by submission and reject stale revision numbers.
- Derive faculty evaluation states (awaiting evaluation, draft, correction, published) from the existing grade table in read-only queries. The grading engine stays the only writer, so the queue cannot disagree with recorded grades. Faculty scope comes from active faculty membership plus active faculty roster, never from the selected role alone. Co-instructors share one queue and one draft per submission.
- Bound the evaluation queue with validated filters and 25-row offset pages. Invalid page numbers show an explicit recovery link instead of silently resetting. Assignment choices come from a title search with 25-row pages, not a full list. Count submissions from currently enrolled students separately from withdrawn students. Above 20 submissions the assignment page reads only the first 20 names and states and sends faculty to the queue, and the focused view reads only the selected submission, because one form per submission does not scale. Revisit keyset pagination if measured queue sizes exceed a few thousand rows per faculty member.
- Omit fixed date windows such as "due this week" from faculty mission control until the pilot agrees their meaning; show the next five deadlines in order instead.
- Target Vercel with managed PostgreSQL per the product owner's selection. Use a dedicated staging project and separate migration credentials.
