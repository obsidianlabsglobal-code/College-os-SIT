# Motion specification

Implemented hover feedback uses the 140 ms shared background transition, disabled for reduced motion. Navigation collapse updates instantly. Keep status changes readable as text and never animate a metric to its real value.

For future panels, use 180–240 ms opacity or transform where movement conveys origin. For future dialogs and drawers use 180–260 ms with immediate keyboard and pointer availability and a functional reduced-motion equivalent. Animate a transport marker only between accepted recent observations. Stop movement when tracking becomes stale, paused, cancelled or complete.
