# Motion specification

CSS handles press (95 ms), hover (140 ms), menus (160 ms), reveal (200 ms) and drawers (240 ms). The sidebar and mobile sheet remain operable while visual state changes. Native dialogs support Escape and restore focus. Confirmed server actions expose status text. Failure uses an alert.

The student priority record and its authorized detail can share a document transition name. The identity includes institution, workspace role, entity type and exact record ID. Browsers without document transitions follow the same record link normally. Timetable day/week navigation retains its date. AURA academic lookup navigates to a specific persisted request and focuses its receipt.

The reduced-motion media rule disables animated travel and nonessential transitions. Keep counts and source timestamps immediately readable. Performance evidence and outstanding device checks are recorded with the [visual review](evidence/living-atmosphere/README.md).
