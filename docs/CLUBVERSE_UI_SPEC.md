# CLUBVERSE UI

The shared shell exposes CLUBVERSE to student, faculty and administrator workspaces. The directory supports scoped name/purpose search, category filtering, proposal forms and the reviewer queue. Recognized club pages show rules and events, with member, organizer and reviewer controls based on server-resolved grants.

Use shared action forms, plain-text status, compact event panels and responsive grids. Show registration and verified participation independently. Event logistics and evidence are text fields in this release. The organizer console is part of club home. Separate global event search, approvals with confirmation dialogs, and richer member states are roadmap work.
