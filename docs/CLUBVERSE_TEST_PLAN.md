# CLUBVERSE test plan

Run the NEXUS smoke checks plus PostgreSQL and Chromium suites using fictional accounts and a local migration credential. The integration suite covers unrecognized and cross-tenant access, stale proposal decisions, unauthorized review, duplicate requests and registrations, scope isolation, advisor limits, role revocation, archive denials, invalid capacity, registration closure, concurrent final-seat allocation, transactional audit rollback, attendance evidence, and ownership transfer.

The Chromium journey covers founder submission, human approval, mobile membership request, officer review, event approval and registration, evidence and completion, and handover. The fixture advances the database event start for the final test stages without changing production time behavior. Test invitation-only and open membership, suspension/reactivation, large club lists, and varied accessibility tools before institutional use.
