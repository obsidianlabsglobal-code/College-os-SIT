# AURA security and evaluation

Rate policy bounds previews to 20 per hour per institution member and 200 per institution. Database locks serialize budget admission. The execution policy allows one preview and one persisted event draft operation for this version. Provider timeout is a cooperative abort signal. No model credential, token budget spend or external data processing is configured.

The integration tests cover extra privilege fields, another institution, another owner, an ordinary club member, a revoked grant, expired approval, cancellation, replay and a text field that asks to bypass approval. The deterministic provider treats that field as content. Browser testing checks confirmation before the persisted draft appears. Model prompt-injection resistance, retrieval provenance, cost/latency evaluation and provider outage recovery require an approved provider and evaluation dataset.

Before operational AI use, establish task retention, disclosure, provider data boundaries, approved sources, and sensitive-action review. Use durable task execution only where a real worker can enforce recovery and cancellation.
