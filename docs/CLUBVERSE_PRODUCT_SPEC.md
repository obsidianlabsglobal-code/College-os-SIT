# CLUBVERSE product specification

The core joins campus discovery, governed recognition, membership, events and leadership handover using the existing NEXUS identity and PostgreSQL.

Categories cover technical, academic, entrepreneurship, sports, creative, service, faculty and special-purpose communities. The migration supplies reference categories and four optional templates. Recognition remains an institution-admin decision. A proposal records name, purpose, rules, category, template, audience and joining policy. SIT-specific rules and recognized organizations require institutional input.

The current slice uses one founder and one active lead. Private member content is represented by member-only events. The event slice includes location, local schedule, audience, capacity, requirements, approval, publication, registration, and verified attendance with written evidence. It omits venue reservations, ticketing and payments. Future packs include projects, announcements, sports, confidential research, finance and verified achievements.
