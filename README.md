# NEXUS College OS

NEXUS is Obsidian Labs' higher-education platform. The first release connects course administration, assignments and feedback, notices, enrollment-letter requests, and academic reporting. SIT Mysuru is the proposed pilot.

## Run locally

Use Node 24 and npm. In the repository root run `npm ci` and copy `.env.example` to `.env`. Set `BETTER_AUTH_SECRET` to a fresh value generated by `openssl rand -hex 32`.

Run `npm run db:local` in a separate terminal. This starts PostgreSQL on loopback and persists its files in the ignored `.nexus-db` directory. A separately installed PostgreSQL 15 or newer is supported with the same connection variables and a pre-created restricted `nexus_app` login.

```sh
npm run db:migrate
NEXUS_DEMO_SEED=1 npm run db:seed
npm run dev -- --hostname 127.0.0.1
```

Open http://127.0.0.1:3000/login. See [Demo guide](docs/DEMO_GUIDE.md) for fictional sign-ins and workflows.

## Verify and release

```sh
npm run lint
npm run typecheck
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

Keep PostgreSQL running for the integration and browser tests. Playwright can use an installed Chromium via `CHROMIUM_PATH`. The browser suite starts the production build when a server is unavailable.
